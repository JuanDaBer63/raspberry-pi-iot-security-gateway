# raspberry-pi-iot-security-gateway
Raspberry Pi-based IoT security gateway implementing firewall rules, network traffic filtering, SSH access control, NAT, IP forwarding, and security testing with Nmap and Kali Linux.

Implementación de un gateway de seguridad para IoT basado en Raspberry Pi, utilizando iptables para control de tráfico, filtrado de red, restricción de acceso SSH, NAT, reenvío IP y pruebas de seguridad con Nmap y Kali Linux.
